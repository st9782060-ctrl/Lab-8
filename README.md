# Lab-8
# Лабораторна робота №8: Організація одновимірних масивів

**Тема:** Оголошення, ініціалізація та опрацювання елементів одновимірних масивів у мові програмування C++.

## Виконані завдання

1. **Задача 1 (`code_1`):** оголошення одновимірного масиву цілих чисел розміром $m = 12$ та його впорядкування за зростанням і за спаданням за допомогою методу обміну (сортування бульбашкою).
2. **Задача 2 (`code_2`):** пошук першого максимального елемента у заданому непорожньому масиві та заміна нулями всіх від'ємних елементів, розташованих перед ним.

## Висновок
Під час виконання практичного заняття було закріплено навички роботи з одновимірними масивами в мові C++, організації циклів для перебору елементів за індексами, пошуку екстремальних значень та сортування масивів.
